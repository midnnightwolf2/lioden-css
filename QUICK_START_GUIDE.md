## 🚀 Installation (3 Easy Steps)

### Step 1: Install the CSS
1. Open the file `cssfiles/GetaTheme_552029.css`
2. Select ALL the text (Ctrl+A or Cmd+A)
3. Copy it (Ctrl+C or Cmd+C)
4. Go to your Lioden den page
5. Click "Edit Den" or "Settings"
6. Find the **CSS section**
7. Paste the CSS (Ctrl+V or Cmd+V)
8. **Save changes**

### Step 2: Add Your Content
1. Open the file `htmlfiles/GetaTheme_552029_html.txt`
2. Copy the sections you want (examples below)
3. Go to your Lioden den **HTML editor**
4. Paste the HTML
5. **Customize the text** with your pride information
6. **Save changes**

### Step 3: Enjoy!
Visit your den page and see your new Roman Empire-themed den in action! ⚔️

## ✏️ Customization Tips

### Change Text Colors
Add this to any text:
```html
<p style="color: #FFD700;">Golden text!</p>
<p style="color: #B22222;">Red text!</p>
<p style="color: #F5F5F5;">White text!</p>
```

### Add Section Dividers
```html
<div class="roman-divider"></div>
```
Adds a fancy golden line between sections

### Make Text Glow
Add this to any element:
```html
<div class="glow-gold">This will glow!</div>
```

### Animated Glow Effect

## 🆘 Common Issues & Fixes

### "My CSS isn't showing!"
✅ Make sure you copied the ENTIRE CSS file  
✅ Check that you clicked "Save" after pasting  
✅ Clear your browser cache (Ctrl+Shift+Delete)  
✅ Try a different browser

### "Images aren't loading"
✅ Check your internet connection  
✅ Wait a few seconds - external images may load slowly  
✅ Try refreshing the page

### "My HTML looks broken"
✅ Make sure every `<div>` has a matching `</div>`  
✅ Check for missing quotation marks  
✅ Try removing sections one at a time to find the problem

### "I want to change an image"
1. Find the section in the CSS file (e.g., `.pride-overview`)
2. Look for the `background: url('...')` line
3. Replace the URL with your new image URL
4. Save and refresh!
